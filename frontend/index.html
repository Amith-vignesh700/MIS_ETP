Diagnosis-Based Protocols

Clinical response pathways activated automatically by the AI diagnosis. Each class maps to a validated oncology escalation protocol.

Class 0 · Benign

Routine Surveillance

Uniform stiffness. No malignant pattern detected.

  • Schedule follow-up elastography in 12 months.
  • Maintain routine clinical monitoring schedule.
  • No biopsy required at this stage.

Strain Pattern

Homogeneous · Low CNR · Smooth boundaries

Class 1 · Precancerous

Close Monitoring

Heterogeneous stiffness. Early-stage dysplasia pattern.

  • Confirmatory ultrasound biopsy recommended.
  • Multidisciplinary team review required.
  • Repeat elastography in 3–6 months.

Strain Pattern

Heterogeneous · Moderate CNR · Irregular zones

Class 2 · Malignant

Urgent Intervention

High stiffness contrast. Irregular invasion boundaries.

  • Immediate oncology referral required.
  • Core-needle biopsy without delay.
  • Staging MRI/CT imaging recommended.

Strain Pattern

Stiff irregular lesion · High CNR · Invasive margins

Signal Processing Stack

01
2D-DFT Bandpass Filter (0.05–0.45 Nyquist)
02
Hankel Matrix Embedding (time-delay, m=F//2)
03
Exact DMD Decomposition (SVD + eigendecomp)
04
Rayleigh Noise Augmentation (sim-to-real)

Deep Learning Architecture

CNN
U-Net Encoder (1→16→32→64→128 ch)
RNN
Bidirectional LSTM (hidden=256, 8 frames)
OPT
ADMM + Proximal SGD (TV regularisation)
OUT
Focal Loss + Softmax (3-class probabilities)
